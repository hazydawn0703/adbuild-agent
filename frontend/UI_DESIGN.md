# 项目 UI 设计标准

项目所有弹窗使用 `app/Modal.tsx`，视觉和滚动规则统一由 `app/modal.css` 管理。工作台登录、项目预授权、默认配置、创建项目、配置编辑、字段映射、执行记录、搭建前预览及其嵌套编辑，以及平台后台的开通空间、添加管理员、重置密码、启用和停用确认均遵循此标准。禁止另建遮罩或使用浏览器 confirm 代替产品确认弹窗。

## 结构与滚动

- 标题与关闭按钮位于固定的 `.modal-header`；保存、取消等操作位于固定的 `.modal-footer`。
- 表单采用 `.modal-form`，正文放入唯一的 `.modal-body`。只滚动正文，不允许整个弹窗滚动，也不通过负偏移的 sticky 模拟固定按钮。
- 全局错误放在固定错误区域；提交失败保留输入，不关闭弹窗。
- 使用原生 `dialog.showModal()` 管理遮罩、焦点约束和焦点恢复。Esc 关闭；提交中禁用关闭和重复提交。打开弹窗时锁定页面滚动。
- Tab 和 Shift+Tab 在当前弹窗内循环。嵌套弹窗关闭时只恢复父弹窗焦点，保持页面滚动锁定；关闭最外层后恢复原滚动状态。
- 需要初始输入焦点的控件标记 `data-modal-autofocus`，由共享组件在打开后聚焦，避免对尚未打开的弹窗调用焦点操作。
- 搭建预览的大面板也必须分离标题、正文和底部确认区，其正文复用相同滚动条标准。

## 尺寸与控件

- 桌面使用双列字段布局，手机切换为单列；小屏仍须同时看见标题、关闭和底部操作。
- 以 `100dvh` 限定高度，桌面至少留出上下各 24px，手机上下各 16px。表单字段可留空时使用“待补充”，不自动写入推断值。
- 监听 `visualViewport` 的高度及顶部偏移，随软键盘或浏览器可视区变化调整弹窗位置和高度。手机输入控件至少 16px，底部预留安全区。
- 长标题、工作表名、提示和标识符允许换行；表格固定布局。执行记录使用正文内可换行的只读文本，不嵌套 textarea 滚动区。搭建确认勾选放在正文，底部保留简短提示及确认按钮，避免小屏按钮被长说明挤出。
- 复用 `.policy-form`、`.policy-grid`、输入框、选项卡和按钮的绿色设计语言；禁止向用户展示可编辑 JSON。
- 金额和平台 ID 使用字符串，避免数字精度变化；时间编辑必须明确时区。保存保留打开时的版本号，不随后台轮询更新覆盖。

## 项目统一滚动条与后台标题栏

所有页面、工作台面板、表格和弹窗的横向与纵向滚动条统一由 `app/scrollbar.css` 定义，在根布局全局引入。统一使用 `--scroll-thumb`（`#bfd3b0`）、`--scroll-track`（`#f2f6ed`）和 `--scroll-hover`（`#a2bc91`），细滚动条、圆角滑块，同时覆盖标准 `scrollbar-color` 与 WebKit 伪元素。禁止在局部组件中另设滚动条配色。

平台后台 `/ops` 的 `.ops-header` 使用 `position:sticky;top:0`，保持不透明背景及独立层级；页面纵向滚动或表格横向滚动时，顶部品牌和管理操作保持可见。手机端标题栏可换行并自适应高度。弹窗位于标题栏上方，不受吸顶层级干扰。

## 验收

在桌面和 390px、320px 手机宽度检查：正文滚动前后标题和底部操作位置不变；只有正文产生滚动；无水平溢出；键盘焦点不会离开弹窗；Esc 和取消不保存；错误不清空输入；保存请求保持金额精度、时区和版本校验。

另外覆盖 667×375 横屏、390×330 低高度可视区、长连续文本及后台长邮箱，验证底部按钮实际可点击而非仅在 DOM 中存在。软键盘高度变化采用可视区事件模拟验收，发布时检查工作台与平台后台全部入口。

Playwright 默认每次生成独立的时间戳与随机标识结果目录。手工指定 `--output` 时也必须选择全新目录；Playwright 会清理该目录，禁止复用任何已有的测试或封存证据路径。
