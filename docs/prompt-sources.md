## 验收

现有真实 Excel 和构造场景全部为开发数据。用户验证集在完整功能通过并冻结后接收。冻结包含 commit、提示词 SHA256、模型及请求参数、依赖锁、评分器、时间基准、重试限制。

正常澄清与人工改错分开计数。首次完整输出先封存再评分，保留分子／分母与每次重复结果。揭示后的验证案例只可称复测，不再称独立盲测。模型供应商可能更新别名对应的底层模型，需记录运行日期与实际响应模型标识。
