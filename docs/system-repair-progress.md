- 逐素材核对历史，混合已有/新增素材阻断整批误跳过；重复素材及真实组排期参与去重。

- 纯消息候选支持有来源的显式结构；比例按用户原始权重核实并以分为单位计算。
- 正常澄清驱动与原单次回归分别运行；模型记录保留完整工具调用参数。
- 发布候选修正联合字面量丢失propertyNames枚举的问题；帖子不带授权码不再表示素材权限缺失。
- 预算分配为受限动作，模型仅提交已有组ID、正权重和有依据的总额；服务端保留节点并分配金额，采纳时重新核验完整结构。
- 只保留row/cell两种来源绑定；URL派生帖子ID和平台沿用同一服务端核验；错误变换在已确认映射中保留其他合法字段。
- 问题观察实际目标节点的证据，其他组修改不使问题重复；结构回答按用户事实记录，后续分析处理，无需编辑JSON。

根级代表输入仅供文件编译使用；实体字段必须指定其实际所有者，最终预览以显式广告组、素材值为准。
