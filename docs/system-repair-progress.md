- 服务端将来源行组装为计划、广告组、素材；重复计划/组预算不重复累计，冲突阻断确认。

## 发布前验收

- 已接入实体目标编辑和批量回答；共享字段更新同步到实际所有者；问题按目标与证据版本失效。
- 逐素材核对历史，混合已有/新增素材阻断整批误跳过；重复素材及真实组排期参与去重。
- 旧协议草稿返回409，保留原资料但必须新建任务重做，旧确认及旧检查点不能沿用。
- 纯消息候选支持有来源的显式结构；比例按用户原始权重核实并以分为单位计算。
- 正常澄清驱动与原单次回归分别运行；模型记录保留完整工具调用参数。
